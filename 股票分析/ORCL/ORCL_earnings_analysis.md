# 【ORCL】Oracle Corporation - 财报与财务分析报告

**报告日期**: 2026-03-11
**报告期间**: Q3 FY2026 (截至2026年2月28日) — 2026年3月10日发布
**财年说明**: Oracle 财年截止于每年5月31日，Q3 FY2026 覆盖 2025年12月-2026年2月

---

## 执行摘要

Oracle 在 Q3 FY2026 交出了**15年以来最强季报**：总营收 $17.2B (+22% YoY)，有机收入和 Non-GAAP EPS 首次同时突破 20% 增长。云收入 $8.9B (+44% YoY) 是核心驱动力，其中 Cloud Infrastructure (IaaS) 增长 84%，Multicloud Database 收入暴增 531%。然而，公司正经历**史无前例的资本开支周期** (FY2026 指引 $50B CapEx)，导致自由现金流深度转负 (-$21.8B YTD)，总债务飙升至 $134.6B。RPO 高达 $553B (+325% YoY) 提供强大的收入可见性，但这一数字的可持续性和转化率值得密切关注。

**核心判断**: 盈利质量良好 (OCF/NI=1.68x)，但公司正处于前所未有的 **"战略性现金消耗期"**，以 AI 基础设施军备竞赛换取未来增长。
