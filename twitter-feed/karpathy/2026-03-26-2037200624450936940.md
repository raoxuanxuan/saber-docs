## 摘要

Karpathy 指出构建 AI 应用的真正瓶颈不是代码编写，而是 DevOps 生态的组装（支付、认证、数据库、域名等服务集成）。他期待 Agent 能自主完成从服务配置到生产部署的全流程。Stripe CEO Patrick Collison 发布的 Stripe Projects 正是朝这个方向迈出的一步——通过 CLI 命令让 Agent 自动配置第三方服务。

## 内容

当我大约一年前构建 menugen 时，我发现最难的部分远远不是代码本身，而是你必须像组装宜家家具一样拼凑的大量服务。我真的很期待有一天，我可以简单地告诉我的 Agent："构建 menugen"，然后它就能搞定一切——从服务配置、获取 API 密钥、开发调试到生产部署。

整个 DevOps 生命周期必须变成代码，以 Agent 原生的人体工学设计。人类不应该需要访问网页或点击按钮。

> Patrick Collison (@patrickc)：Stripe Projects 让 Agent 从 CLI 即时配置服务。`stripe projects add posthog/analytics` 即可自动创建账户、获取 API 密钥并设置计费。
