## 内容

很高兴发布新仓库：nanochat！（这大概是我写过的最疯狂的项目之一。）

与此前只涵盖预训练的 nanoGPT 不同，nanochat 是一个最小化的、从零开始的、全栈训练/推理流水线，用于构建一个简单的 ChatGPT 克隆，且依赖极少。你只需启动一台云 GPU 机器，运行一个脚本，最快 4 小时后就能在类 ChatGPT 的 Web UI 中与你自己的 LLM 对话。

整个项目约 8,000 行相当整洁的代码，涵盖：

- 使用新的 Rust 实现训练 tokenizer
- 在 FineWeb 上预训练 Transformer LLM，评估多项指标的 CORE 分数
- 在 SmolTalk 的用户-助手对话、多选题、工具使用数据上进行中期训练
- SFT，在世界知识多选题（ARC-E/C, MMLU）、数学（GSM8K）、代码（HumanEval）上评估
- 可选地在 GSM8K 上用"GRPO"进行强化学习
- 高效推理引擎：KV cache、prefill/decode、工具使用，通过 CLI 或 ChatGPT 风格 WebUI 交互
- 生成一份 Markdown 报告卡，总结和游戏化整个过程

即使只花约 $100（8xH100 节点约 4 小时），你就能训练一个可以简单对话的小型 ChatGPT 克隆。约 12 小时可超越 GPT-2 的 CORE 指标。进一步扩展到约 $1000（约 41.6 小时），模型会变得更加连贯，能解决简单的数学/代码问题。
