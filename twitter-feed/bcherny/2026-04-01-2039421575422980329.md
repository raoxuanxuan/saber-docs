## 内容

Today we're excited to announce NO_FLICKER mode for Claude Code in the terminal. It uses an experimental new renderer that virtualizes the entire viewport. Most internal users already prefer it.

Upsides: no flickering, no jumping, constant memory/CPU, mouse events support.
Downsides: native cmd-f doesn't work (use ctrl+o then /).
