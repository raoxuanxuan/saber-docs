## 内容

**【公告】** 从 2026-04-04 太平洋时间 12:00 起，Claude 订阅将不再覆盖 OpenClaw 等第三方工具的使用量。

你仍可通过 Claude 账号登录这些工具，但需要额外购买用量包（现提供折扣），或改用 Claude API Key。

**【原因】** 我们一直在努力应对 Claude 需求的快速增长，而现有订阅方案的设计并未考虑第三方工具的使用模式。算力资源是需要审慎管理的，我们优先保障通过官方产品和 API 使用 Claude 的客户。

**【补偿方案】** 订阅用户将获得等额于月费的一次性积分补偿。如需更多用量，现可购买折扣用量包。如需全额退款，请留意明日邮件中的退款链接。

**【长期策略】** 我们希望审慎管理业务增长，以长期可持续地服务客户。此次调整是朝这一目标迈出的一步。
